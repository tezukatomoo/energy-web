# 東京都環境計画書 消費電力量集計ツール (energy_web)

Streamlit製の専用部・共用部PDF集計ツール。

## 機能
- 専用部PDF（住戸別の一次エネ計算書）から消費電力量を抽出
- 共用部PDF（非住宅版エネルギー消費性能計算書）から建物全体・太陽光削減量を抽出
- 住戸リストCSVと組み合わせて建物全体の消費電力量を集計
- Excel / PDF レポート出力

## 対応PDFフォーマット
- 共用部PDF: Ver.3.10 (2026.04) 以降の新形式（4ページ目に二次エネ、太陽光は正値）
- 旧形式（3ページ目に二次エネ、太陽光はマイナス符号）も後方互換

## ローカル実行（推奨・ネット接続不要）

デスクトップの **「東京都環境計画書 消費電力量集計ツール」** ショートカット、
または本フォルダの **`energy-web起動.bat`** をダブルクリックするだけ。

- 自動でブラウザが開く: http://localhost:8501
- ログインパスワード: `energy2026`
- 終了するときは黒い画面を閉じる（または Ctrl + C）
- 二重起動しても既存の画面をブラウザで開き直すだけ
- 初回だけ `.venv`（Python仮想環境）を自動作成してライブラリを入れる

`.bat` は **Shift-JIS + CRLF** で保存すること。UTF-8やLF改行にすると
cmd.exeが読み違えて起動しなくなる。

### 手動で動かす場合
```bash
pip install -r requirements.txt
streamlit run app.py
```

## デプロイ
Render の Blueprint (`render.yaml`) で自動構成。
※ Renderの無料枠（月750インスタンス時間／アカウント全体）を使い切ると
サービスが停止するため、常用はローカル実行を推奨。
